# AKIM AI — Telegram bot

Персональный Telegram-ассистент с режимами: универсальный, учёба, спорт, бизнес и планирование. Сохраняет историю диалога в `data.json` на сервере.

## 1. Создать Telegram-бота

1. Открой Telegram и найди официального `@BotFather`.
2. Отправь `/newbot`.
3. Укажи имя, например `AKIM AI`.
4. Придумай username, который заканчивается на `bot`, например `AkimPersonalAI_bot` (если свободен).
5. BotFather выдаст токен. Сохрани его в секрете — это пароль от управления ботом.

## 2. Подготовить сервер

Нужен постоянно работающий Node.js сервер (Node 20+). На компьютере для теста:

```bash
npm install
cp .env.example .env
```

Открой `.env` и заполни:

- `TELEGRAM_BOT_TOKEN` — токен от BotFather;
- `OPENAI_API_KEY` — API-ключ OpenAI Platform;
- `OPENAI_MODEL` — доступная в твоём API модель (по умолчанию `gpt-5.5`);
- `OWNER_TELEGRAM_ID` — необязательно, числовой Telegram ID владельца, чтобы закрыть доступ посторонним.

Запуск:

```bash
npm start
```

Пока процесс работает, бот отвечает в Telegram. Для круглосуточной работы проект нужно развернуть на хостинге, который поддерживает постоянный Node.js-процесс. Не загружай `.env` в GitHub и не отправляй токены в чат.

## Команды

`/start`, `/help`, `/mode`, `/study`, `/sport`, `/business`, `/plan`, `/reset`.

## Важно

- Telegram-бот не может работать сам по себе: ему нужен постоянно работающий сервер.
- Использование OpenAI API оплачивается отдельно от подписки ChatGPT.
- История хранится локально в `data.json` без шифрования. Для публичного/боевого запуска следует использовать защищённое хранилище и ограничить доступ через `OWNER_TELEGRAM_ID`.
- Это стартовая версия: веб-поиск, голос, календарь и выполнение действий во внешних сервисах пока не подключены.
